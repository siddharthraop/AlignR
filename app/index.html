How you know it works

AlignR holds out TPU7x. It drafts the TPU7x topics from the v5p and v6e topics and the TPU7x values, and then compares each draft with the page that Google published.

Known limits. AlignR drafts what has a sibling. A concept that's new in a generation, such as the TPU7x dual-chiplet design, gets a stub with questions instead of prose. lxml checks the grammar but doesn't apply the default attribute values that DITA processing needs, so DITA-OT still builds every topic in CI.

Draft a held-out generation

Drafts from tpu-v6e-* and tpu-v5p-* sibling topics and facts/tpu7x.yaml. Each draft calls Gemini, so public drafts are capped per day. A set takes about a minute.
