# AlignR developer docs

AlignR drafts a new hardware generation's DITA topics from the sibling topics of earlier generations and a launch
facts file, then gates every draft before a writer sees it. These pages are for people who run, change or extend it.
For using AlignR, see the [user help](https://siddharthraop.github.io/AlignR/help/) and the [user guide (PDF)](https://siddharthraop.github.io/AlignR/help/alignr-user-guide.pdf).
